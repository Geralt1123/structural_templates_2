# ☕ Структурные шаблоны Декоратор и Заместитель на примере кофейни

Учебный проект с двумя структурными шаблонами: **Декоратор (Decorator)** и **Заместитель (Proxy)**.
Оба примера построены вокруг одной темы — **кофейни**. Шаблоны устроены похоже: оба оборачивают объект
в другой объект с тем же интерфейсом. Поэтому их удобно изучать вместе и сравнивать.

В каждом шаблоне есть работающий пример и **задание**: нужно добавить свой код и проверить его тестами.

## 🚀 Как начать

### В браузере (GitHub Codespaces), ничего не нужно устанавливать

1. Нажмите зелёную кнопку **Code** → вкладка **Codespaces** → **Create codespace on main**.
2. Подождите 1–2 минуты: окружение соберётся само, и pytest установится автоматически.
3. Откройте терминал (`` Ctrl+` ``) и выполните:

```bash
python main.py   # демо всех шаблонов
pytest           # проверить все задания
```

### Локально

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
python main.py
pytest
```

Изучайте шаблоны по порядку:

## ✏️ Как выполнять задания

1. Прочитайте `README.md` шаблона и код примера.
2. Найдите в коде комментарий `# ЗАДАНИЕ` и добавьте свой код.
3. Запустите тесты шаблона, например:

   ```bash
   pytest tests/test_decorator.py
   ```

   - `PASSED` — тест прошёл ✅
   - `SKIPPED` — задание ещё не выполнено; в конце вывода будет подсказка, что нужно сделать
   - `FAILED` — код добавлен, но работает неправильно; прочитайте сообщение об ошибке

4. Снова запустите демо шаблона: ваш код появится в выводе.

Тесты также можно запускать в панели **Testing** (значок колбы слева).
