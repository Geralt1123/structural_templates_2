# Декоратор (Decorator)

## Какую проблему решает

К любому напитку в кофейне можно добавить молоко, сироп, сливки, ещё шот эспрессо — в любом
количестве и сочетании. Если делать это наследованием, классы размножаются взрывообразно:

```
EspressoWithMilk, EspressoWithMilkAndSyrup, AmericanoWithSyrupAndCream, ...
```

а «двойной карамельный сироп» вообще не выразить без нового класса.

**Декоратор** оборачивает объект в другой объект **с тем же интерфейсом**. Обёртка добавляет своё
поведение и передаёт вызов дальше — обёрнутому объекту. Обёртки можно вкладывать друг в друга
и собирать нужную комбинацию прямо во время работы программы:

```python
WhippedCream(Syrup(Milk(Americano(), "овсяное"), "карамель"))
```

## Структура

```
                    Beverage (Компонент)
                 ┌──────────────────────┐
                 │ + description()      │
                 │ + cost()             │
                 └──────────▲───────────┘
            ┌───────────────┼──────────────────┐
     Espresso, Americano,   │        CondimentDecorator (Базовый декоратор)
     Tea                    │        ┌───────────────────────────────┐
     (Конкретные            └────────│ _beverage: Beverage  ◆────────┼──▶ обёрнутый напиток
      компоненты)                    │ cost() -> _beverage.cost()    │
                                     └───────────────▲───────────────┘
                                    ┌────────────────┼────────────────┐
                                  Milk             Syrup         WhippedCream
                           cost() = _beverage.cost() + своя надбавка
```

Как считается цена `WhippedCream(Syrup(Milk(Espresso())))`:

```
WhippedCream.cost() ──▶ Syrup.cost() ──▶ Milk.cost() ──▶ Espresso.cost() = 120
       +50          ◀──     +30      ◀──    +40      ◀──
                                                      итого: 240 ₽
```

## Декораторы в Python

В Python есть синтаксис `@`, и он реализует ту же идею, только для функций:

```python
@takeaway
def checkout_takeaway(beverage): ...

# то же самое, что:
checkout_takeaway = takeaway(checkout_takeaway)
```

`takeaway` принимает функцию и возвращает новую функцию с теми же аргументами,
которая вызывает исходную и добавляет к результату 20 ₽. `functools.wraps` копирует
в обёртку имя и docstring исходной функции.

> Синтаксис `@` и шаблон Декоратор — не одно и то же. Шаблон оборачивает **объекты**,
> и делается это во время работы программы. `@` обычно оборачивает **функции и классы**
> один раз, при их объявлении. Идея при этом общая.

## Когда применять

- Нужно добавлять объектам обязанности на лету, не меняя их класс.
- Комбинаций дополнительных возможностей так много, что наследование приведёт к взрыву числа классов.
- Нельзя или неудобно наследоваться от класса (он из чужой библиотеки или помечен как финальный).

Примеры из стандартной библиотеки: `io.BufferedReader` оборачивает «сырой» файл, добавляя буфер;
`functools.lru_cache` оборачивает функцию, добавляя кэш.
